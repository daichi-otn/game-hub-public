## 構成

- `index.html`: ハブのページ
- `games-data.js`: ゲーム一覧のデータ(タイトル、URL、アイコンなど)
- `games/`: ハブから遊べるゲーム(ジオメトリ・ダッシュ、クイズ 2 種、ホリホリドリラー)と、アイコンの画像

新しいゲームは、`games-data.js` に 1 件追加すると一覧に載ります。
